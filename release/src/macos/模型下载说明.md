# 衍像｜EvolveShot — 模型下载说明（macOS 版）

本安装包**不含任何模型文件**（全量约 110GB，按需下载即可）。

**先分清模型放哪：**
- **远端模式（推荐）**：模型放在**GPU 机器**的 ComfyUI 目录里（GPU 机通常装的是 Windows 版或
  Linux ComfyUI），Mac 上不放任何模型。下表「放置目录」以那台机器的 ComfyUI 为基准。
- **本机模式**：模型放在 Mac 本机的 ComfyUI 目录（见《安装说明-macOS.md》本机模式章节）。

**最省事的方式**：在**运行 ComfyUI 的那台机器**上打开衍像系统（Windows 版）→「模型配置」页
→ 缺失模型一键拉取（hf-mirror 国内镜像、断点续传、自动放对目录）。下表前 14 个已内置地址；
其余在弹窗粘贴下表「下载地址」即可（`huggingface.co` 链接会自动改走 hf-mirror）。

**文件名必须与下表完全一致**，放错目录「模型配置」页会显示缺失。

## 七、图像理解模型（首尾视频「看图写提示词」用）

不在 ComfyUI 目录，放在**衍像应用根目录**（与 `server/` 平级）：`qwen3-vl-2b/`，整目录约 4.0GB。

```bash
export HF_ENDPOINT=https://hf-mirror.com
pip3 install -U huggingface_hub
huggingface-cli download Qwen/Qwen3-VL-2B-Instruct --local-dir qwen3-vl-2b
```

或浏览器打开 https://hf-mirror.com/Qwen/Qwen3-VL-2B-Instruct/tree/main 逐个下载全部文件放进该目录
（须有 `config.json`）。远端模式下由**GPU 机侧**的衍像安装承担，Mac 不用放。
