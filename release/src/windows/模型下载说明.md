# 衍像｜EvolveShot — 模型下载说明（Windows 版）

本安装包**不含任何模型文件**（全量模型约 110GB，按需下载即可）。各功能所需模型、大小、
放置目录、下载地址见下表。**文件名必须与下表完全一致**，放错目录会导致「模型配置」页显示缺失。

## 最省事的方式：系统内一键拉取

启动系统（`start.bat`）→ 浏览器打开 http://127.0.0.1:9666 → 登录（默认 `videoadmin / admin123`）
→ 左侧菜单 **模型配置**：三个页签（首尾视频 / 文生图 / 视频生成）列出各自所需模型，
缺失的模型点 **拉取** 即自动下载——走 hf-mirror 国内镜像、支持断点续传、自动放入正确目录。

- 下表前 14 个（一~三节 + 帧插值）已内置下载地址，页面上直接点拉取即可；
- 广告图三件套、超分、NSFW LoRA 未内置地址：点拉取时在弹窗里粘贴下表对应「下载地址」即可
  （粘贴 `huggingface.co` 的地址会自动改走 hf-mirror，不必手动换域名）。

## 七、图像理解模型（首尾视频「看图写提示词」用）

不在 ComfyUI 目录，放在**解压根目录**（与 `server\` 平级）：`qwen3-vl-2b\`，整目录约 4.0GB、14 个文件。

```bat
:: 方式一：命令行整目录下载（推荐，先切国内镜像）
set HF_ENDPOINT=https://hf-mirror.com
pip install -U huggingface_hub
huggingface-cli download Qwen/Qwen3-VL-2B-Instruct --local-dir qwen3-vl-2b
```

方式二：浏览器打开 https://hf-mirror.com/Qwen/Qwen3-VL-2B-Instruct/tree/main 逐个下载全部文件
（大头是 model.safetensors 3.96GB），全部放进 `qwen3-vl-2b\`，目录内须有 `config.json`。
